# הכסף שלי — אפליקציית iPhone לניהול כספים

אפליקציית iOS מקורית (Swift + SwiftUI + SwiftData + App Intents) לניהול כספים אישיים ועסקיים, בעברית מלאה, בלי שרת ובלי מנוי.
פרטי הארכיטקטורה והחישובים: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## ⚠️ מצב האימות — חשוב לקרוא
הפרויקט נכתב על מחשב **Windows ללא Xcode**. לכן:
- ✅ **הליבה הפיננסית (`Kesef/Core`) קומפלה ונבדקה** עם Swift 6.4.3 ל-Windows: **43 בדיקות, 0 כשלונות** (כסף ועיגול, יתרות, מניעת ספירה כפולה, חיובים קבועים ומעברי חודש/שנה, תחזית ותרחישים, סכום פנוי, תקציבים, ממוצעי הכנסה, יועץ חיסכון, כפילויות Apple Pay, ייבוא/ייצוא CSV).
- ✅ **האפליקציה המלאה קומפלה ב-Xcode** על Mac בענן (GitHub Actions), ו**כל 58 הבדיקות עברו על סימולטור אייפון** — כולל 15 בדיקות האינטגרציה מול SwiftData (קליטת Apple Pay, כפילויות, אישור, פיצול, דחייה, חיובים קבועים, גיבוי ושחזור).
- ❌ **המסכים לא נבדקו ידנית** (לחיצות, עיצוב, RTL) — רק קומפלו.
- ❌ **אוטומציית Apple Pay לא נבדקה על מכשיר אמיתי.**

השלבים בהמשך מסבירים איך לקמפל, להריץ את הבדיקות ולבדוק על האייפון.

## מה צריך
- **Mac** עם **Xcode 16 ומעלה** (חינם מה-App Store). אין דרך להתקין אפליקציה כזו על אייפון בלי Mac (או שירות Mac בענן).
- אייפון עם **iOS 17 ומעלה**.
- Apple ID. חשבון חינמי מספיק, אבל: האפליקציה תפוג אחרי **7 ימים** ויהיה צריך להתקין שוב מ-Xcode (הנתונים נשמרים). חשבון מפתח בתשלום (99$ לשנה) — תוקף של שנה.

## התקנה על האייפון
1. העתק את התיקייה `KesefApp` ל-Mac ופתח את `Kesef.xcodeproj` ב-Xcode.
   (אם הקובץ לא נפתח: `brew install xcodegen` ואז `xcodegen` בתיקייה — ייווצר פרויקט חדש מ-`project.yml`.)
2. בחר את ה-target **Kesef** ← לשונית **Signing & Capabilities** ← **Team**: בחר את ה-Apple ID שלך.
3. שנה את **Bundle Identifier** למשהו ייחודי, למשל `il.yourname.kesef` (וגם ב-target של הבדיקות: `il.yourname.kesef.tests`).
4. חבר את האייפון בכבל, בחר אותו כיעד בראש החלון, ולחץ ▶︎ (Run).
5. באייפון: **הגדרות ← כללי ← VPN וניהול התקנים** ← אשר את המפתח. ב-iOS 16+ גם: **הגדרות ← פרטיות ואבטחה ← מצב מפתח** ← הפעל (דורש הפעלה מחדש).
6. פתח את האפליקציה, הוסף חשבון ראשון עם היתרה הנוכחית שלו, ואשר התראות.

## הרצת הבדיקות
- ב-Xcode: **Product ← Test** (⌘U). מריץ את בדיקות החישובים (`Tests/FinanceCoreTests`) ואת בדיקות האינטגרציה מול SwiftData (`KesefTests`).
- בדיקות החישובים בלבד, מהטרמינל ב-Mac: `swift test` בתיקייה הראשית.

## הגדרת אוטומציית Apple Pay (פעם אחת, באייפון)
ההוראות המלאות מופיעות גם בתוך האפליקציה: **עוד ← אוטומציית Apple Pay**.
1. אפליקציית **קיצורים** ← **אוטומציה** ← **+** ← **ארנק** (Wallet / Transaction).
2. בחר את הכרטיסים. **אל תסנן לפי קטגוריה.**
3. **הפעל מיד** (Run Immediately) ← הבא ← **אוטומציה ריקה חדשה**.
4. הוסף פעולה ← חפש "הכסף שלי" ← **רישום רכישת Apple Pay**.
5. סכום ← **קלט קיצור ← סכום (Amount)**. בית עסק ← **קלט קיצור ← סוחר (Merchant)**. כרטיס ← **קלט קיצור ← כרטיס / שם**.
6. סיום. בהפעלה הראשונה iOS עשוי לבקש "אפשר תמיד".
7. **בדיקה:** בצע רכישת Apple Pay קטנה בהצמדה למסוף. צריכה להופיע התראה "זוהתה רכישה חדשה" ועסקה בלשונית **ממתינות**, מסווגת כ**אישית**.
   ב-**עוד ← אוטומציית Apple Pay** יופיע מתי הפעולה רצה לאחרונה. עד שזה קורה, המסך מציג שהאוטומציה **לא נבדקה**.

(שמות התפריטים בעברית עשויים להשתנות מעט בין גרסאות iOS.)

### מגבלות Apple Pay שאי אפשר לעקוף
- עובד רק בתשלום **פיזי** (הצמדה למסוף). רכישות אונליין ובתוך אפליקציות — בדרך כלל לא.
- iOS מעביר רק סכום, בית עסק וכרטיס, **בלי מזהה עסקה**. לכן הכפילויות נבדקות לפי סכום + בית עסק + כרטיס + חלון זמן: הפעלה חוזרת תוך 3 דקות נחסמת; רכישה זהה מאוחרת יותר (עד 6 שעות) נוצרת עם סימון "ייתכן כפילות" ושני כפתורים.
- לפעמים הסכום מגיע 0 או השם ריק → העסקה נפתחת להשלמת פרטים. לפעמים האוטומציה לא רצה בכלל (תלוי בחברת האשראי) → מוסיפים ידנית או מייבאים CSV.
- אין גישה ישירה לרכישות ב-Wallet, ולא נעשה שימוש ב-API פרטי או ב-FinanceKit.

## מה יש באפליקציה
- **בית:** יתרה נוכחית (מאומת), הכנסות/הוצאות החודש (מאומת), הכנסות צפויות והוצאות עתידיות (תחזית), תחזית לסוף החודש, סכום פנוי לשימוש, עסקאות ממתינות, אזהרות, חלק השותף, 14 הימים הקרובים, כפתור **+ הוצאה**.
- **תנועות:** חיפוש, סינון לפי חודש/סוג/אישי-עסקי, עריכה ומחיקה.
- **הכנסה/הוצאה:** סכום, תיאור, תאריך, אישי/עסקי, קטגוריה ותת-קטגוריה, חשבון, אמצעי תשלום, קבועה/משתנה, סטטוס, הערה, קבלה, חוזרת, פריסה לתשלומים, תבניות, תשלום חלקי, זיכוי.
- **ממתינות + מסך אישור:** אישית מסומנת מראש, מעבר לעסקית עם קטגוריות מתאימות, תיקון סכום, פיצול אישי/עסקי שסכומו שווה למקור, אשר ושמור / עריכה / דחה, אזהרת כפילות, שיוך כרטיס לחשבון.
- **חיובים קבועים:** תדירויות, יום חיוב, סיום, השהיה, סכום משתנה, תזכורות, יצירת ממתינה ביום החיוב.
- **תזרים:** 7/14/30 יום, שמרני/בסיסי/אופטימי, גרף, לוח חיובים, אזהרת מינוס, הנחות התחזית ותאריך עדכון היתרה.
- **תקציבים, דוחות** (CSV ו-HTML קריא), **חיסכון ויעדים** (ממוצעי 3/6/12, חודש חלש/חזק, המלצות עם הסבר), **שותף** (אחוז מהרווח או מההכנסות), **ייבוא CSV** (תצוגה מקדימה, התאמת עמודות, תאריכים ישראליים, Windows‑1255, כפילויות), **גיבוי ושחזור** עם SHA‑256, **Face ID**.
- **Siri / קיצורים:** "הוסף הוצאה", "מצב כספי", "עסקאות ממתינות".
