# התקנה חינמית על האייפון מ-Windows (Sideloadly)

בלי Mac ובלי 99$. החיסרון: Apple מגבילה חשבון חינמי ל-**7 ימים** — אחר כך מתקינים שוב (הנתונים נשמרים).

## מה צריך
- המחשב הזה (Windows), כבל USB לאייפון, ה-Apple ID שישמש לחתימה.
- הקובץ **`install\Kesef.ipa`** בתיקיית הפרויקט (נבנה אוטומטית ב-GitHub).
- מומלץ: **Apple ID נפרד** רק לזה (לא החשבון הראשי). Sideloadly מבקש את הסיסמה כדי לחתום.

## פעם ראשונה (כ-20 דקות)
1. **iTunes ו-iCloud ל-Windows** — הורד מ-apple.com (לא מה-Microsoft Store; Sideloadly דורש את הגרסאות מאתר Apple) והתקן.
2. **Sideloadly** — הורד מ-sideloadly.io והתקן.
3. חבר את האייפון בכבל → באייפון אשר **"סמוך על מחשב זה"**.
4. פתח Sideloadly:
   - בשדה **iDevice** — בחר את האייפון.
   - גרור את **`Kesef.ipa`** לחלון (או לחץ על סמל ה-IPA ובחר אותו).
   - בשדה **Apple account** — הזן את ה-Apple ID → **Start**.
   - הזן סיסמה וקוד אימות דו-שלבי אם יתבקש (אתה מזין — לא אני).
5. באייפון: **הגדרות ← כללי ← VPN וניהול התקנים** → בחר את ה-Apple ID → **אמון**.
6. באייפון: **הגדרות ← פרטיות ואבטחה ← מצב מפתח** → הפעל → האייפון יופעל מחדש → אשר "הפעל".
7. פתח את **"הכסף שלי"** ✓

## כל 7 ימים
חבר את האייפון (או אותה רשת Wi-Fi, אם הפעלת את האפשרות ב-Sideloadly), פתח Sideloadly, בחר שוב את אותו `Kesef.ipa` → Start.
**הנתונים נשמרים** כל עוד מזהה האפליקציה זהה. אם עברו 7 ימים — האפליקציה פשוט לא תיפתח עד החידוש; שום דבר לא נמחק.

## עדכון לגרסה חדשה
כשאני מוסיף תכונות, נבנה `Kesef.ipa` חדש → מתקינים אותו באותה דרך מעל הקיים. הנתונים נשמרים.

## אחרי ההתקנה
1. הוסף חשבון ראשון עם היתרה הנוכחית (בית → "הוספת חשבון ראשון").
2. **עוד ← הגדרות** → אשר התראות, ובדוק: עוסק מורשה ✓, 18%, דו-חודשי.
3. **עוד ← שותף** → מרום 50% מהרווח (כבר מוגדר).
4. **עוד ← אוטומציית Apple Pay** → הוראות הגדרת הקיצור.
5. **עוד ← ייבוא דוח** → קובץ Excel/CSV של הוצאות או הכנסות.

## בעיות נפוצות
- **"Untrusted Developer"** — שלב 5.
- **האפליקציה לא נפתחת אחרי שבוע** — זה ה-7 ימים; התקן שוב.
- **Sideloadly לא מזהה את האייפון** — ודא ש-iTunes מאתר Apple מותקן, ושאישרת "סמוך על מחשב זה".
- **"Maximum number of apps"** — חשבון חינמי מוגבל ל-3 אפליקציות כאלה; מחק אחת ישנה.
